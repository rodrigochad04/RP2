DADOS BRUTOS ORIGINAIS
======================

Os sete arquivos exatamente como foram baixados das fontes, sem nenhum
recorte, filtro ou alteração. SNIS e IDEB aqui são NACIONAIS.

Como usar com os scripts do pacote de análise (analise.zip):

  1. Copie esta pasta para dentro da pasta do pacote de análise.
  2. Abra recortar_brutos.py e ajuste a constante ORIGINAIS para apontar
     para cá:  ORIGINAIS = Path("dados_brutos_originais")
  3. Rode:  python3 recortar_brutos.py
     Isso regenera dados_brutos/ a partir destes arquivos.
  4. Siga a partir do passo 1 do README (build.py).

O MD5SUMS.txt permite conferir a integridade:  md5sum -c MD5SUMS.txt
